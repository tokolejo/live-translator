# 🎙️ OBS Live Speech Translator (ქართული ⇄ English)

სრულიად მზა, დამოუკიდებელი და უფასო ვებ-აპლიკაცია სინქრონული თარგმნისთვის Google Chrome-ისა და OBS Studio-სთვის. **არ საჭიროებს OpenAI-ს, Gemini-ს ან სხვა ფასიან API გასაღებებს.**

---

## ✨ ძირითადი შესაძლებლობები
1. **ქართული ⇄ English:** თარგმნის როგორც ქართულიდან ინგლისურზე, ისე ინგლისურიდან ქართულზე ერთი ღილაკით (`⇄`).
2. **მყისიერი + გრამატიკულად ზუსტი თარგმანი:** საუბრისას ლაივში გამოაქვს სიტყვები, ხოლო პაუზისთანავე აზრობრივად და გრამატიკულად ალაგებს მთლიან წინადადებას (სიტყვები არ იკარგება).
3. **OBS Studio Overlay Ready:**
   - **გამჭვირვალე რეჟიმი (Transparent / Ultra Clean)**
   - **ქრომაკეი (Green Screen)**
   - **Glassmorphism Dark & Cyber Neon** სტილები.
4. **Auto-Reconnect (უწყვეტი რეჟიმი):** Chrome-ის მიკროფონის ავტომატური გადატვირთვა პაუზების დროს, რათა სტრიმის განმავლობაში მოსმენა არასდროს გაითიშოს.
5. **სწრაფი კლავიში:** დააჭირეთ **`H`** კლავიატურაზე მართვის პანელის დასამალად / გამოსაჩენად.

---

## 🚀 როგორ გამოვიყენოთ:

### 1. გახსნა Google Chrome-ში:
1. გახსენით ფაილი `index.html` პირდაპირ Google Chrome-ში (ორმაგი კლიკით) ან გაუშვით `start_translator.bat`.
2. მიეცით Chrome-ს მიკროფონის გამოყენების ნებართვა (*Allow microphone*).
3. აირჩიეთ სასურველი მიმართულება (მაგ. 🇬🇪 ქართული ➔ 🇺🇸 English).
4. დააჭირეთ **„ჩართე მოსმენა“** და დაიწყეთ საუბარი.

---

### 2. OBS Studio-ში ოვერლეიდ (Overlay) დამატება:

#### მეთოდი A: Window Capture (ყველაზე მარტივი და რეკომენდებული)
1. გახსენით `index.html` Chrome-ში ცალკე ფანჯარაში.
2. ჩართეთ მოსმენა და დააჭირეთ **`H`**-ს (ან ღილაკს „OBS რეჟიმი“), რათა მენიუ დაიმალოს და დარჩეს მხოლოდ სუფთა სუბტიტრის ბარი.
3. OBS Studio-ში დაამატეთ ახალი წყარო: **`+` ➔ `Window Capture` (ფანჯრის ჩაწერა)** ➔ აირჩიეთ Chrome-ის ეს ფანჯარა.
4. (სურვილისამებრ) თუ აირჩევთ სტილს *🟩 Green Screen*, OBS-ში მარჯვენა კლიკით დაადეთ ფილტრი: `Filters ➔ Chroma Key`.

#### მეთოდი B: OBS Browser Source
1. OBS-ში დაამატეთ: **`+` ➔ `Browser` (ბრაუზერის წყარო)**.
2. მონიშნეთ **`Local file`** და აირჩიეთ `index.html`-ის მისამართი.
3. გაფართოება მიუთითეთ: `Width: 1920`, `Height: 1080`.
4. სტილში აირჩიეთ `Ultra Transparent` სრულიად გამჭვირვალე ფონისთვის.
