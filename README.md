# 🎙️ IICE 2026 — Live Conference Speech Translator & Operator Studio (ქართული ⇄ English)

უფასო, ნულოვანი დამოკიდებულების (zero-dependency) ვებ-აპლიკაცია სინქრონული მეტყველების ამოცნობისა და რეალურ დროში თარგმნისთვის (**English ⇄ ქართული**), შექმნილი **IICE 2026** საერთაშორისო სამეცნიერო კონფერენციის, პროექტორის ორეკრანიანი რეჟიმისა (Stage Display) და OBS Studio ტრანსლაციებისთვის.

**არ საჭიროებს OpenAI-ს, Gemini-ს ან სხვა ფასიან API გასაღებებს** — მუშაობს Google Chrome-ში Web Speech API-ის, ადგილობრივი კონფერენციის ცოდნის ბაზისა და მდგრადი თარგმანის მექანიზმის მეშვეობით.

## ✨ ძირითადი შესაძლებლობები

### 1. 3-სვეტიანი ოპერატორის სტუდია (`index.html`)
- **სექცია და მომხსენებელი (მარცხენა სვეტი):**
  - კონფერენციის **6 სექცია** და **103 რეგისტრირებული მომხსენებელი** (`IICE_SPEAKERS`), აფილიაციის ბარათითა და პროექტორზე მომხსენებლის 1-კლიკიანი წარდგენის ბანერით (`📢 პროექტორზე წარდგენა`).
  - **ხელით ტექსტი და სწრაფი ტესტი:** ფრაზის აკრეფა და Enter-ზე დაჭერა მომენტალურად თარგმნის და უშვებს სუბტიტრს პროექტორზე.
  - **საინფორმაციო ბანერები:** 1 კლიკით პროექტორზე გასაშვები სლაიდები — *☕ ყავის შესვენება*, *❓ კითხვა-პასუხის სესია*, *⏱️ ტექნიკური პაუზა* და ბანერის გათიშვა.
  - ყველა ბარათი იკეცება/იშლება (`collapse`) და იმახსოვრებს მდგომარეობას `localStorage`-ში.
- **პროექტორის მონიტორი და ლოგები (ცენტრალური სვეტი):**
  - მინიატურული **Live Stage Monitor** რეალურ დროში გადახედვითა და ტესტ-ფრაზების ციკლით.
  - **სრული თარგმანის ლოგები (`IndexedDB`):** ინახავს სესიის ფრაზებს (`IICE_Translator_DB`, `localStorage` fallback-ით), ასრულებს დუბლიკატების ფილტრაციას, აქვს ლაივ ძიება და ექსპორტი **CSV**, **TXT** და **JSON** ფორმატებში.
- **აუდიო, ინტელექტი და პროექტორის ვიზუალი (მარჯვენა სვეტი):**
  - მიკროფონის მოწყობილობის არჩევა და რეალურ დროში აუდიო-მეტრი.
  - **⚡ Watchdog ავტო-გაცოცხლება:** თუ მიკროფონში ხმა შედის, მაგრამ Chrome-ის SpeechRecognition 4.5 წამზე მეტხანს გაჩერდა, სისტემა ავტომატურად გადატვირთავს მოსმენას.
  - პარაზიტი სიტყვების გაწმენდა, ჭკვიანი პუნქტუაცია, 2-ხაზიანი კინო-ლიმიტი და სიჩუმისას ავტომატური გაქრობის ტაიმერი (`3s` / `5s` / `8s` / `გამორთული`).
  - **4 სწრაფი პრესეტი** (`🏛️ დიდი დარბაზი`, `🎬 კინო`, `📺 Broadcast`, `🪟 OBS`) და **13 ვიზუალური სტილი** (მათ შორის `OLED Pure Black`, `Apple Keynote Pill`, `Cinema Bottom Fade`, `Broadcast News Ticker`, `Cyber Neon`, `Academic Slate`, `Frosted Glass`, `Ghost Outline`, `Clean Transparent`, `Studio Light`, `Green Screen`, `Blue Screen`, `Custom Color`), შრიფტის ზომების, სიგანის (%), გამჭვირვალობის, პოზიციისა და სწორების კონტროლით.

### 2. ცალკე პროექტორის სცენა (`stage.html` + `stage.js`)
- იხსნება ცალკე ფანჯარაში ღილაკით **„🖥️ პროექტორის გახსნა“** მეორე მონიტორზე ან დარბაზის პროექტორზე გადასატანად.
- სინქრონიზდება ოპერატორის კონსოლთან რეალურ დროში `BroadcastChannel('iice_subtitles_sync')`-ის საშუალებით (სუბტიტრები, სტილები, პოზიცია, ზომები და საინფორმაციო ბანერები).
- **ავტომატურად დამალვადი Quick Control Toolbar:** მაუსის მოძრაობისას პროექტორის ეკრანის ზედა ნაწილში ჩნდება სწრაფი მართვის ზოლი (პოზიცია, სწორება, შრიფტის ზომა `A-/A+`, `a-/a+`, ორიგინალის ჩვენება/დამალვა, სიგანე, სტილი, გასუფთავება, სრული ეკრანი), რომელიც სტრიმს/პროექციას არ უშლის ხელს.

### 3. სამდონიანი თარგმანის ძრავა და სამეცნიერო ცოდნის ბაზა
1. **მომხსენებლის ბილინგვური თეზისების ბაზა (`abstracts_data.js` — `IICE_ABSTRACTS_DB`):**
   - შეიცავს **103 თეზისს** და **352 დაწყვილებულ ქართულ-ინგლისურ წინადადებას**.
   - როდესაც არჩეულია კონკრეტული მომხსენებელი და ნათქვამი ფრაზა ≥72%-ით ემთხვევა მისი თეზისის წინადადებას, სისტემა მყისიერად აჩვენებს ოფიციალურ აკადემიურ თარგმანს.
2. **კონფერენციის ტერმინოლოგიური ლექსიკონი (`623 ტერმინი`):**
   - მოიცავს ქიმიის, ნანოტექნოლოგიის, გარემოს დაცვის, სურსათის ქიმიის ტერმინებს, მეცნიერთა სახელებსა და ინსტიტუტებს (`curated_iice_glossary.txt` / `DEFAULT_IICE_GLOSSARY`).
   - ჩაშენებული **ლექსიკონის მოდალი** (`📖 ლექსიკონი`): ძებნა, კატეგორიებით ფილტრაცია (*ქიმია & ტექნოლოგია*, *მეცნიერები*, *ინსტიტუტები*), სწრაფი დამატება/წაშლა, ტექსტური რედაქტორი (`ქართული: English`), IICE-ის საბაზო ლექსიკონის აღდგენა და `.txt` ექსპორტი.
3. **ASR შეცდომების ავტო-კორექცია და ფონეტიკური Snapping:**
   - ასწორებს Chrome-ის ქართული მეტყველების ამომცნობის სისტემურ დამახინჯებებს (სახელები, ქიმიური ტერმინები, `2026` და სხვ.).
   - Levenshtein-ის მანძილითა და ბიგრამების შეერთებით ასწორებს დამახინჯებულ სამეცნიერო ტერმინებს აქტიური მომხსენებლის საკვანძო სიტყვების (`kwg` / `kwe`) მიხედვით.
4. **მდგრადი მანქანური თარგმანი + Anti-Flicker Guard:**
   - იყენებს Google Translate-ის რამდენიმე სარეზერვო endpoint-ს (`dict-chrome-ex`, `it`, `gtx`) ქეშირებითა და `Latest-Request-Wins` დაცვით (`translationSeq`), რათა ნელმა მოთხოვნებმა არ გადააწეროს უფრო ახალი ფრაზა.

## 🚀 გაშვება და გამოყენება

### ლოკალური სერვერით გაშვება (რეკომენდებული)
`BroadcastChannel`-ის (`index.html` ⇄ `stage.html` სინქრონიზაცია) და მიკროფონის ნებართვების სტაბილურად მუშაობისთვის სასურველია აპლიკაცია გაეშვას `localhost`-ზე:

1. გაუშვით **`start_translator.bat`** (ორმაგი კლიკით).
   - სკრიპტი ავტომატურად იწყებს ლოკალურ HTTP სერვერს პორტზე `8080` (`python -m http.server 8080`, ხოლო თუ Python არ არის დაყენებული — Windows-ის ჩაშენებულ PowerShell სერვერს `server.ps1`-ით) და ხსნის `http://localhost:8080/index.html`-ს Google Chrome-ში.
   - ალტერნატიულად, შეგიძლიათ პირდაპირ გაუშვათ PowerShell სერვერი:
     ```powershell
     powershell -NoProfile -ExecutionPolicy Bypass -File server.ps1 -Port 8080
     ```
2. მიეცით Chrome-ს მიკროფონის გამოყენების ნებართვა (*Allow microphone*).
3. საჭიროების შემთხვევაში აირჩიეთ სექცია/მომხსენებელი, ენის მიმართულება (`🇺🇸 English ➔ 🇬🇪 ქართული` ან `🇬🇪 ქართული ➔ 🇺🇸 English`) და დააჭირეთ **„ჩართვა“**-ს (`P` ან `Space`).
4. მეორე ეკრანზე ან პროექტორზე გასაშვებად დააჭირეთ **„🖥️ პროექტორის გახსნა“**, გადაიტანეთ გახსნილი `stage.html` ფანჯარა პროექტორის ეკრანზე და დააჭირეთ **`F`**-ს (სრული ეკრანი).

## 🎥 OBS Studio-ში გამოყენება

- **მეთოდი A: Window Capture (რეკომენდებული)**
  1. გახსენით `stage.html` (ღილაკით „პროექტორის გახსნა“) ან გამოიყენეთ `index.html` და დააჭირეთ **`H`**-ს ზედა პანელის დასამალად.
  2. სტილში აირჩიეთ `Clean Transparent`, `Green Screen (OBS)` ან `Blue Screen (OBS)`.
  3. OBS Studio-ში დაამატეთ წყარო **`+` ➔ `Window Capture`** და მიუთითეთ Chrome-ის შესაბამისი ფანჯარა.
  4. `Green Screen` / `Blue Screen` რეჟიმის შემთხვევაში OBS-ში დაამატეთ ფილტრი: `Filters ➔ Chroma Key`.
- **მეთოდი B: OBS Browser Source**
  - მართვის ზოლის გარეშე პირდაპირ ჩასატვირთად გამოიყენეთ URL: `http://localhost:8080/index.html?overlay=1` (`Width: 1920`, `Height: 1080`). *(შენიშვნა: `BroadcastChannel` სინქრონიზაცია მუშაობს ერთსა და იმავე ბრაუზერის კონტექსტში, ამიტომ `stage.html`-თან დაკავშირებისას გამოიყენეთ Chrome + Window Capture.)*
